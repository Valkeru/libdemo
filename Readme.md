# Общие правила

## Сервисы
+ Сервисы, содержащие бизнес-логику отделяются от остальных. Напрямую в контроллеры и другие подобные классы
  такие сервисы включать запрещено;
+ В контроллер включаются сервисы из пакета `ru.valkeru.libdemo.service.http`. Сервисы с бизнес-логикой включаются в них,
  в них же выполняются операции по предварительной обработке данных
(разбор загруженных файлов, работа с файловой системой и прочие);
+ Запрещено включать сервисы друг в друга (за исключением случаев, подобных описанным в п.2). Для получения данных от
  другого сервиса следует использовать `Helper implements ApplicationContextAware`, зависимости Helper должен извлекать
  из контекста и хранить в статических полях. Аналогичное требование предъявляется к компонентам, которые используются
  сервисами, в т.ч. транзитивно;
+ Запрещается вызывать `@Transactional` методы сервиса из его же методов напрямую. При необходимости вызова таких
  методов также следует использовать `Helper` для получения ссылки на экземпляр сервиса;
+ Следует избегать возврата Entity из сервиса, за исключением случаев, когда это действительно необходимо.
  Каждый такой случай должен быть сопровождён комментарием в javadoc с объяснением необходимости
  и с `TODO` на дальнейшую переработку. Исключение — маппинг данных. 

## Сущности, репозитории и DTO
+ Поля, входящие в ID сущности должны иметь тип `Long`;
+ Сущности должны содержать подробное описание всех ключей и связей;
+ Сущности должны иметь аннотацию `@ToString`, а также `@ToString.Exclude` на Lazy связях и всех коллекциях;
+ Запросы для удаления данных из БД должны быть определены вручную с использованием `@Query`;
+ DTO должны размещаться в пакете `ru.valkeru.libdemo.model.dto`. При необходимости создать DTO в другом пакете, новый
  пакет должен быть добавлен в список
  `ru.valkeru.libdemo.config.persistence.ClassImportIntegratorProvider.dtoClassesPackages`
  Все вложенные пакеты, содержащие DTO, должны быть перечислены отдельно;
+ В качестве проекций для JPA используются DTO из пакетов, перечисленных в
  `ru.valkeru.libdemo.config.persistence.ClassImportIntegratorProvider.dtoClassesPackages`.
  Другие виды проекций создавать запрещается.
  При необходимости выборки ограниченного набора данных следует создать в DTO конструктор с требуемым набором полей;
+ `SELECT` следует выполнять в DTO-проекцию, а не в Entity
+ Для ограничения видимости полей в ответе применяются аннотации `@JsonView`.
+ Коллекции:
  + Типы возвращаемых значений и параметров объявляются как `Collection<Type>`;
  + Типы коллекций в Entity объявляются как `List<Type>`
  + Типы коллекций в DTO объявляются как `Collection<Type>`
